仿真配置文件

Adapter 可选；MatFilter 可显式选择，留空时从代码仓自动推导唯一候选。

Adapter（可选） 本地文件由 Connector/SDK 与其他输入一起直传，不经过 Linux Web 服务。
MatFilter（可选） 与 SDK 使用相同路径和直传语义，不生成 Web 专用上传引用。
